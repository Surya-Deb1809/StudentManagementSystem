# Student Management System

A console-based Student Management System built using Java, JDBC, Maven, and MySQL.

## Features

- Add Student
- View All Students
- Search Student by ID
- Search Student by Name
- Update Student
- Delete Student
- Student Statistics
- Input Validation
- Duplicate Student ID Check
- MySQL Database Integration

## Technologies Used

- Java
- JDBC
- MySQL
- Maven
- Git & GitHub
